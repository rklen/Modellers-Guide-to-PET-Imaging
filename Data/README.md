# Modeller's Guide to PET Imaging / Data
In the book we have used time-activity curves from 6 PET scans and each scan has various ROIs. Here is a list of the data files:
1. 11C-carfentanil, brain PET scan, 16  time frames, input and 2 ROIs
2. 11C-raclopride, brain, PET scan, 13 time frames, 2 ROIs
3. 15O-water_1, total body PET scan, 24 time frames, input and 9 ROIs
4. 15O-water_2, total body PET scan, 24 time frames, input and 8 ROIs
5. 18F-FDG,  brain PET scan, 14 time frames, input and 4 ROIs
6. 18F-FDOPA, total body PET scan, 16 time frames, 3 ROIs
